# Security

Report security problems privately, never in a public issue: on GitHub, open the repository's **Security** tab and choose **Report a vulnerability**, or email hello@gigaikripaservices.com with "SECURITY" in the subject.

We acknowledge reports within 3 working days. The full policy, with the timeline and the scope, is [SECURITY.md](https://github.com/cbsshekhawat18-lab/gigai-tools/blob/main/SECURITY.md).
