# Contributing

The full guide is [CONTRIBUTING.md](https://github.com/cbsshekhawat18-lab/gigai-tools/blob/main/CONTRIBUTING.md) in the repository. In short:

- Report a bug as an [issue](https://github.com/cbsshekhawat18-lab/gigai-tools/issues/new/choose), with a file that fails if you can share one.
- Propose a new tool in an issue before writing it.
- Process files in the browser where you can; a feature that needs a server says so first.
- Run `npm run typecheck`, `npm test` and `npm run build` before you open a pull request.

Everyone taking part follows the [Code of Conduct](https://github.com/cbsshekhawat18-lab/gigai-tools/blob/main/CODE_OF_CONDUCT.md).
